# Pac-Man audio sources

These files were extracted from the [ClassicGaming.cc Pac-Man sounds page](https://www.classicgaming.cc/classics/pac-man/sounds). Each linked ZIP contained one WAV file; only that playable WAV is included here. The project owner confirmed reuse terms privately.

| Cue | Local file | Source archive |
| --- | --- | --- |
| `intro` | `pacman_beginning.wav` | [pacman-beginning.zip](https://www.classicgaming.cc/classics/pac-man/files/sounds/pacman-beginning.zip) |
| `chomp` | `pacman_chomp.wav` | [pacman-chomp.zip](https://www.classicgaming.cc/classics/pac-man/files/sounds/pacman-chomp.zip) |
| `fruit` | `pacman_eatfruit.wav` | [pacman-eatfruit.zip](https://www.classicgaming.cc/classics/pac-man/files/sounds/pacman-eatfruit.zip) |
| `ghost` | `pacman_eatghost.wav` | [pacman-eatghost.zip](https://www.classicgaming.cc/classics/pac-man/files/sounds/pacman-eatghost.zip) |
| `extraLife` | `pacman_extrapac.wav` | [pacman-extrapac.zip](https://www.classicgaming.cc/classics/pac-man/files/sounds/pacman-extrapac.zip) |
| `intermission` | `pacman_intermission.wav` | [pacman-intermission.zip](https://www.classicgaming.cc/classics/pac-man/files/sounds/pacman-intermission.zip) |
| `death` | `pacman_death.wav` | [pacman-death.zip](https://www.classicgaming.cc/classics/pac-man/files/sounds/pacman-death.zip) |
| `frightened` | Synthesized in Web Audio | No separate clip on the source page |

The WAVs are mono, 8-bit PCM at 11,025 Hz, except `pacman_chomp.wav` at 22,050 Hz.
